# 基于PathCoT的病理视觉推理系统

《大模型原理与技术》2026 年课程综合作业 · 02-Multimodal

本项目使用公开的 LLaVA-1.5-7B 权重，针对单张病理图像实现图像描述、视觉问答和 PathCoT 分阶段推理。思考模式依次展示任务规划、专家观察、证据聚合与答案复核。原生网页支持图像浏览、局部区域分析和多轮对话。
